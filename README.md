# SkillBridge AI – Google & Instagram Hybrid Frontend Edition (v3.0)

SkillBridge AI features an iconic **Google-style Search & Workspace** layout combined with an **Instagram-style Social Skill Feed & Stories** interface.

---

## 🎨 Frontend Highlights

### 1. 🔍 Google-Style Frontend Experience
- **Multi-Color Google Branding**: Iconic Google-colored logo (`S k i l l B r i d g e AI`).
- **Google Search Capsule Bar**:
  - Centered pill search bar with instant autocomplete dropdown.
  - Voice search microphone (🎙️) and Google Lens (📷) buttons.
  - Google-style action buttons: **Google Skill Search** & **I'm Feeling Confident ✦** (which jumps straight to a random challenge or doubt resolution).
  - Quick role filter chips (*Data Analyst*, *Frontend Dev*, *Python Dev*, *ML Engineer*, *Full-Stack*, *Cloud & DevOps*).
- **Google 9-Dot App Launcher (Waffle Menu)**:
  - Accessible on every page from the top right.
  - Quick access grid to all 9 SkillBridge workspaces (*Search*, *AI Doubts*, *InstaSkill*, *Missions*, *Passport*, *Sprint*, *Interview*, *Confidence*, *Growth*).
- **Google User Avatar**:
  - Shows user profile circle with real-time earned points badge.

---

### 2. 📸 Instagram-Style Skill Feed ("InstaSkill")
- **Instagram Stories Carousel**:
  - Docked at the top of the feed with iconic Instagram rainbow gradient rings (`#f09433`, `#e6683c`, `#dc2743`, `#cc2366`, `#bc1888`).
  - Micro-learning stories covering SQL tricks, React gotchas, Python 1-liners, ML data leakage traps, and Docker optimization.
- **Full-Screen Instagram Story Viewer**:
  - Auto-advancing 5-second progress bars, tap to advance left/right, and quick heart reactions.
- **Instagram Post Stream & Explore**:
  - User cards with avatar rings, role badges, and verified checkmarks.
  - Media cards with gradient backgrounds and syntax-highlighted code snippets.
  - Action bar: **Heart Like button with real-time counter**, **Double-tap on media for floating heart animation**, comment bubble, share link, and bookmark.
  - Post creation modal to share project milestones, certificates, and solved doubts directly to the peer feed.

---

### 3. 📊 Deep Competency Blueprint (Multi-Skill Matrix Mode)
- **Proficiency Selectors**: *Familiar (50%)*, *Proficient (80%)*, *Mastered (100%)*.
- **5-Axis SVG Spider Radar Chart**: Dynamic competency visualization across Coding, Data, Frameworks, Math, and DevOps.
- **Cross-Career Benchmark Matrix**: Benchmarks skills across all 6 roles with a natural pivot recommendation.
- **Interactive "What-If" Skill Simulator**: Click any missing skill to watch your match score and radar chart grow live.

---

### 4. ⚡ Global Floating AI Doubt Assistant Drawer
- Docked at the bottom-right of every page.
- Resolves any question with 5-part clarity, copy-to-clipboard code patterns, and awards +15 points on the spot.

---

## 🚀 Running the App

```powershell
python -m pip install -r requirements.txt
python app.py
```

Open **`http://127.0.0.1:5000`** in your browser.
