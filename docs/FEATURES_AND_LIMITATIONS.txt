SkillBridge AI feature upgrade

This is a rule-based prototype, not a trained AI model. It does not include authentication or separate role portals because the uploaded source project did not contain them. Do not use this as a production multi-user system without adding authentication, authorisation, CSRF protection and privacy/security review.
